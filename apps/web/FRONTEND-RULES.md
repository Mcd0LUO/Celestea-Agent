# Celestea Studio · 前端渲染铁律（FRONTEND-RULES）

> 本文件为 Celestea-Studio 前端（`frontend/`，TypeScript + Vite）的**验收硬性标准**。
> 所有后续前端 worker 必须遵守；违反以下任一铁律 = 验收不过。

## 铁律

1. **禁止「先清空后加载」**
   任何可见区域刷新内容时，禁止先 `innerHTML = ''` / 清空容器再逐条渲染（会产生空白帧）。
   一律**离屏构建**（`document.createElement('div')` 等不挂载容器内完整构建）+ **单次替换**
   （`container.replaceChildren(...off.childNodes)`），旧内容保持可见直到新内容就绪。

2. **树 / 列表刷新禁止整树 innerHTML 重建**
   会话树、提供商列表等层级列表刷新时，禁止整树 `innerHTML` 重建。必须：
   - 局部增量更新（如 worker 组轮询只更新该组）；或
   - 双缓冲 + 一次性替换，并**恢复展开状态**（记录 `details.open`）与输入焦点。

3. **切换类操作必须防竞态**
   会话切换、pane 切换等异步操作必须带**竞态守卫**（序号 `seq` 递增 + 结果返回时校验
   `seq === 当前`），晚到的旧请求结果一律丢弃，不得覆盖新状态；加载期间只显示轻量指示
   （顶部细进度条 / 状态栏文案），绝不整页空白。

4. **折叠 / 展开必须 CSS transition，不重建 DOM**
   可折叠区域（工作区节点等）的展开/收起只允许通过 class/属性切换 + CSS transition
   （如 `max-height` 过渡，必要时覆盖 UA 默认 `display:none` 以启用动画），
   禁止删除重建子节点；选中态只切 class，不重渲染。

5. **弹窗打开 / 关闭不触发背景视图重渲染**
   modal / 浮层 / 菜单的打开与关闭不得触发其下层背景视图的刷新或重建。

6. **轮询只做局部更新**
   定时轮询（如引擎 Worker 组）只能更新发生变化的局部区域，禁止整页/整树重绘。

7. **设置页 pane 切换零重建**
   左导航切页只切换 class；页面内容首次加载后缓存，切回不重新请求、不重建
   （数据刷新仅由「重新载入」或打开设置页等显式动作触发）。

8. **新增 UI 一律沿用本套纪律**
   任何新增可见区域/组件（含工具卡、信息块、树、列表、弹窗）默认采用上述模式；
   新增 `innerHTML` 赋值前必须自问：是否可以离屏构建后单次替换？

## 验收口径

- 人工/自动化验收时逐项核对上述铁律；出现「空白帧」「整树闪动」「旧结果覆盖新状态」
  任一现象即视为违反。
- `pnpm build`（`tsc --noEmit` 严格模式 + `vite build`）必须通过。
- 后端契约未就绪时允许优雅降级，但不允许以「加载中…」占位整区替换作为常规路径
  （首次空容器除外，且完成后必须单次替换）。
