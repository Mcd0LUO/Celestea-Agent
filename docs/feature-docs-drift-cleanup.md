## 1. 一句话目标

把已经**不再描述现状**的文档按规范**归档**（`git mv` 进 `archive/`，加横幅、改状态、不删正文），
把「文档 ↔ 代码 ↔ 契约」之间**可机械发现**的漂移变成断言，而不是靠人记得。
